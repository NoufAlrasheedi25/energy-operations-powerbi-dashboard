# Energy Operations Dashboard

This project focuses on analyzing energy operations and maintenance data using Power BI.

I started by cleaning and organizing the data in Power Query, then used the data to answer a set of questions related to maintenance costs, faults, outage hours, regions, and asset age.

## Business Questions

- Which stations have the highest maintenance cost?
- Which maintenance types cost the most overall?
- How do faults and outage hours change by month?
- Which regions have the most recorded faults?
- Is higher asset age associated with higher maintenance cost?

## What I Did

- Cleaned and prepared the data using Power Query
- Reviewed missing values and data quality
- Created DAX measures for key metrics
- Built interactive filters for Region, Station, and Maintenance Type
- Created visualizations to answer the main business questions
- Built a Power BI dashboard to present the results clearly

## Tools Used

- Power BI
- Power Query
- DAX
- Excel
